    P-Values

    A p-value measures how unusual a test statistic is under the null model. Read it with the effect estimate and its uncertainty.

    Null Hypothesis Significance Testing

    NHST is the common framework that tests data against a null hypothesis (H0). A conventional cutoff is p ≤ 0.05 to reject H0.

    What a p-value actually is

    The p-value is the probability of getting results as extreme as, or more extreme than, what we observed — assuming the null hypothesis is true.

    A probability for the null given the data requires a model for the alternative and prior odds between the hypotheses.

    How "extreme" is measured

    "Extreme" means far in the test statistic's null distribution. For z/t-based tests we standardize by the standard error. For other tests (e.g., χ², F), extremeness is on those statistics' own scales.

    Common Misinterpretations

    From Goodman's "A Dirty Dozen" — four mistakes that persist across research and industry:

    1. "If p = .05, the null has a 5% chance of being true."
    2. "A non-significant p (> .05) means no difference."
    3. "p = .05 means these exact data would occur only 5% of the time under H0."
    4. "If you reject at p = .05, the Type I error probability for this decision is 5%."

    Use the interval and the planned sensitivity to see which lifts remain plausible. See the A/B interval example.

    Approximate evidence for a regression coefficient

    Compare two nested Gaussian linear regressions fitted to the same data. The null fixes one coefficient at zero. The alternative estimates it freely, while both models include the same other predictors. The formula below uses the difference in Bayesian information criterion (BIC) to approximate the Bayes factor in favor of the null.

    Approximate Bayes factor (BF01) =SQRT(n) * (1 + (T_Stat^2 / df)) ^ (-n / 2)

    Use the ordinary least-squares t-statistic based on the full model’s residual variance, the number of observations n, and the full model’s residual degrees of freedom df. BIC is a large-sample approximation. A Bayes factor computed from a specified prior for the alternative can give a different result.

    Approximate posterior null probability with equal prior odds =BF / (1 + BF)

    Read the estimate with its assumptions

    For 100 observations, 98 residual degrees of freedom, and a t-statistic of 1.60, the formula gives BF01 ≈ 2.75. Equal prior odds give an approximate null probability of 0.73 under the BIC approximation. Other prior odds change that number. To assess whether a result is large enough to act on, compare the estimated effect and interval with a threshold that matters to the decision.
