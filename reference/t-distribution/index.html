    t-distribution

    Critical values for the Student’s t-distribution. Look up the t-value for 1 to 500 degrees of freedom and significance levels from 0.001 to 0.50.

    Critical values of the t-distribution

    Each cell shows the t-critical value for the given degrees of freedom (df) and significance level (α). The α = 0.05 two-tailed column is highlighted as the most commonly used threshold.

    Scroll the table to see more columns on narrow screens.

    Reading the Values
    All values are positive. For a two-tailed test, the critical region is |t| > t-critical (both tails). For a one-tailed test, use the one-tailed α row and apply the cutoff in the prespecified direction. Values are computed from the inverse t-distribution.

    How to use this table

    1. Find your degrees of freedom (df) in the leftmost column. For a pooled-variance two-sample t-test: df = n1 + n2 − 2. Welch’s test uses Welch–Satterthwaite degrees of freedom. The lookup rounds fractional df down to use a conservative critical value. For a one-sample test: df = n − 1. For regression coefficients: df = n − k − 1 (where k is the number of predictors).
    2. Choose your significance level (α) across the top. The standard in most fields is α = 0.05 (two-tailed), which corresponds to a 95% confidence level.
    3. Read the intersection. The value at (df, α) is the critical t-value. For a two-sided test, reject if |t| exceeds this value. For a prespecified upper-tail test, reject if t exceeds it. For a lower-tail test, reject if t is below its negative.

    Two-tailed vs. one-tailed

    The table shows two rows of alpha values in the header:

    Two-tailed α: Used when your alternative hypothesis is “μ ≠ μ0” (the effect could go either direction). The critical region is split across both tails. This is the default in most research.

    One-tailed α/2: Used when your alternative hypothesis specifies a direction (“μ > μ0” or “μ < μ0”). The entire rejection region is in one tail. A two-tailed α = 0.05 corresponds to a one-tailed α = 0.025.

    If you are running a one-tailed test at α = 0.05, look at the column where the one-tailed row says 0.05—which is the two-tailed α = 0.10 column.

    What happens as df grows?

    As degrees of freedom increase, the t-distribution converges toward the standard normal (Z) distribution. The last row of the table (∞) shows the Z-critical values. For df ≥ 120, the difference between t and Z is negligible.

    Interpreting the p-value
    The two-tailed p-value is the probability of observing a t-statistic at least as extreme as yours (in either direction) under the null hypothesis. If p < α, you reject H0. Choose the alternative before looking at the data. Its one-sided p-value is half the two-sided value when the statistic points in that direction, and the complement of that half when it points the other way.
