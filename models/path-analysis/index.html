    Path Analysis

    Specify paths between measured variables and check how well the fitted model reproduces their observed relationships. Interpreting paths as effects requires a credible causal design and assumptions about the arrows.

    Which arrows can the data orient?

    The Path Workbench fits the graph you draw. Here, use conditional independence to learn which arrows the three-node PC exercise can orient. The synthetic examples are jointly Gaussian, where zero partial correlation corresponds to conditional independence.

    Start with all three possible edges. Look for evidence to remove A—C. Then ask whether B belongs to the set that separated them.

    When is the equivalence class justified?

    PC assumes an acyclic data-generating graph, causal sufficiency (no unmeasured common causes among the modeled variables), the causal Markov and faithfulness conditions, and suitable independence tests. Exact cancellation between paths can create a population independence that violates faithfulness. Sampling noise can also make a real association hard to detect, even under faithfulness.

    Under the assumptions, the population target is a completed partially directed acyclic graph (CPDAG). A CPDAG summarizes graphs with the same conditional-independence implications. An undirected edge can have either direction across members of the equivalence class, with directions sometimes changing together. An intervention can supply directional evidence. A null response alone can reflect poor measurement, low power, cancellation, or an absent effect.

    Return to the Path Workbench to fit a specified graph, or to Causal Graphs and Identification to assess identification for an assumed graph.

    Path Workbench

    Use Reading Regressions to review coefficients and uncertainty before fitting a path model.

    Draw a hypothesized graph, then fit it to data. Coefficients are estimated by maximum likelihood, and a χ² test checks whether the drawn structure can reproduce the observed covariances.

    1 · Draw the graph

    Draw an arrow with the From → To bar, or single-click one node then another on the canvas, or tick targets in a node’s editor (double-click the node). Reverse (⇆) or delete (×) arrows from their chips; cycles are rejected. Double-click a node to rename it (names must match your data’s column names), delete it, or mark it as the target outcome. Drag nodes to arrange the diagram.

    3 · Fit the model

    Fitted DAG

    The structure you drew, with the maximum-likelihood estimate printed on each arrow: a 1-standard-deviation increase in the cause changes the effect by β standard deviations, holding its other modeled causes fixed.

    S matrix (covariance)

    Sample covariance of the modeled variables (divisor N − 1). Together with N, this is all the information the fit uses.

    Correlation matrix

    If four customers have activity scores of 1, 2, 3 and 4 and valued purchases of 2, 1, 4 and 3, Pearson’s r is 0.60. It measures linear association and can miss a curved relationship. It is undefined for a constant variable. The ±2/√n guide is a rough single-pair null heuristic. Baseline traits can drive both variables, so the association alone cannot identify the effect of activity on valued purchases.

    S rescaled to unit variances. Amber italic cells are correlations between variables with no direct arrow in your model — if your DAG fits, these arise through chains and shared causes alone.

    Fitted path effects

    Goodness of fit

    χ² = (N − 1) · FML; df = distinct moments − free parameters. Each missing arrow among downstream variables is a testable constraint; exogenous variables covary freely, as in standard path analysis.

    Worked example with the default dataset

    Press Load Default Dataset (400 customers) to draw the four example paths and set repurchase as the target outcome. Press Fit Model. The fitted coefficients are about 0.50 for satisfaction → loyalty, 0.35 for convenience → loyalty, 0.71 for loyalty → repurchase, and 0.18 for convenience → repurchase. The model gives χ²(1) ≈ 1.3 and p ≈ .26, so the global test does not reject its restrictions at α = .05. The specified model places the entire satisfaction-to-repurchase path through loyalty, with a fitted path product of about 0.35. Now delete convenience → repurchase and refit: χ²(2) ≈ 30, p < .001. Compare this nested specification with the original model to assess the added zero restriction.

    How much of advertising’s effect runs through search interest?

    Trace the direct path advertising → sales (c = 1) and the mediated path advertising → search interest (a = 2) → sales (b = 3). These are illustrative unstandardized coefficients. The Path Workbench estimates standardized coefficients from its own data.

    Which contrast supports a decision about the total effect? In the identified linear additive model with no exposure–mediator interaction, the direct effect is c, the indirect effect is a × b and the total is c + a × b. Random assignment of advertising can leave confounding between interest and sales. Calculate products within joint draws, propagate downstream variables for total-effect contrasts, and integrate over the mediator for nonlinear outcomes. Review identification through a mediator.
