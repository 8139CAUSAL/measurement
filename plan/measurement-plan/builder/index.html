    Answer five questions to draft a measurement plan and an implementation table you can export as CSV. KPIs with strong signals are listed first.

    Step 1 — Business model
    What is the main way this site creates value? Measurement starts from the business model — not from GA4 menus.
    →What this means for your measurement plan
    Pick 3-6 primary KPIs
    Start with the few KPIs that most directly track the primary outcome from Step 1. You can add more later. Custom KPIs count as strong signals.

    In the written measurement plan that accompanies this export, define whose outcome counts, the denominator, and when follow-up ends. If you can assign treatment, see Randomized Assignment and Blocking. For historical records, see Causal Graphs and Identification.

    Too many KPIs. Keep to 3-6 for focus.
    Translate KPIs into events
    For each KPI, here's a suggested event name. Edit to match your naming convention. Check whether GA4 already collects the event before adding a tag. GA4 event naming rules.

    In the written plan, record the ID that joins each event to the assigned unit and the window in which the event counts.
